# my/ — the files that make this box yours

Everything you edit lives here, so an update from us never touches it. The one exception is
`.env` (your keys), which stays at the top of the box.

| File | What it is |
|---|---|
| `settings.yaml` | Your board, channel and profile ids — merged over `config/aios.config.yaml` at load. Not secrets; commit it. |
